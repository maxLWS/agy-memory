## 1. `v0.4.0 -> v0.4.1` 评测方法与公平性控制（122 组）

所有端到端实验均在真实无头 Antigravity CLI 下运行（`agy --model <slug> --output-format json --dangerously-skip-permissions --print-timeout 120s [--project <id>] -p <prompt>`）：

- **每轮独立隔离 `HOME`**：每次运行新建临时 `$HOME`，仅拷贝鉴权凭据、空 `settings.json` 与测试用命名项目配置；归档检索题挂载只读硬链接冻结快照（139 条 V1 快照用于 `T1/T7/T9`，190 条 V2 快照用于新增真实题 `F1/F2`，均排除当前开发会话）。子进程启动前清空父环境全部 `ANTIGRAVITY_*` / `AGY_*` 变量。
- **冻结对照臂**：`baseline`（无插件）、`v0.3.0`（冻结旧版）、`head_1b6aaa02`（v0.3 后 schema 膨胀版）、`v0.4.0`（初版项目黑板）、`v0.4.0_no_hint`（关闭兄弟提示消融）与 `v0.4.1`（修掉 Swarm 截断缺陷版）。
- **配对随机种子与跨模型复核**：黑板与首轮开销任务采用多组配对随机参数（`seeds 101, 202, 303`）且每个种子随机打乱对照臂顺序。主测模型为 `gemini-3.8-flash-medium`（`n=102`），并在 `claude-sonnet-5-5-medium`（`n=20`）上复核 `B1–B5` 以排除单模型过拟合。
- **原始日志复算**：全部轮次、工具调用、磁盘溢盘（`output.txt`）、首轮输入 token 与估算计费等效 token（`uncached_input + 0.1 * cache_read + 5 * output`）均直接从原始 `transcript.jsonl` 复算。

#### `F1` 暴露出的真实缺陷与 `v0.4.1` 根治
- **旧版问题（`v0.3.0` 与 `v0.4.0`）**：`src/store.ts` 里的 `read_session(mode="swarm")` 写死了 `bodyClipLen = candidateSlice.length <= 4 ? 1400 : ...`，哪怕精准请求单条消息（`startSeq=79, endSeq=79`）依然在第 1,400 字符处强行腰斩，而尾部提示却误导模型「传 `startSeq/endSeq` 可无截断查看」。真实 3,500 字审计结论的关键修复文件名与最终指标恰好落在 1,400 字之后，导致模型放弃记忆工具、连续跑十余条 shell 查盘最终撞上 120s 超时。
- **`v0.4.1` 根治**：单条消息读取直接释放剩余完整内联预算（约 7,500 字符，总响应仍严守 `<= 8,650` UTF-8 字节），2–4 条切片按剩余预算动态平摊，多条摘要里对任何被截断的消息直接给出 `pass startSeq=N endSeq=N for full message` 提示。
- **\*`F1` 判分透明说明**：`v0.4.1` 在 50.4s / 0 溢盘内完整准确地答出了题面所问的全部 P0-A 截断审计项（27 条截断响应、全部 5 个解析与适配器修复文件/函数、Live `20.0% -> 0.0%` 与 Replay `Δ_CF = 30.0%`）。原自动脚本第 3 条正则误查了另一条不相关 P0-B 的文件名导致自动计分为 4/5，人工逐项核对题面原问准确率为 5/5。

## 5. 诚实边界与已知权衡

1. **不做后台 LLM 自动总结**：坚持全离线零费用。如果会话 A 敲定决定却忘了调 `board_post`，会话 B 靠开场 1 行兄弟活跃提示和按项目隔离的 `search_sessions(conversationId=...)` 回查原日志兜底（`B6` 实测 `3/3` 通过，中位 19.7s）。
2. **不同模型在活跃兄弟提醒下的保守程度差异（`B2`）**：同时看到黑板最新值和 `Activity: 2 other active or recent session(s)` 时，`claude-sonnet-5-5-medium` 直接信任黑板并 1 轮 0 调用秒答（8.5s），而 `gemini-3.8-flash-medium` 会多花几轮去复核兄弟会话（中位 9 轮，仍 `3/3` 通过）。不需要兄弟提醒的用户可设环境变量 `AGY_MEMORY_SIBLING_HINT=0`。
3. **首轮固定前缀成本**：即便较 `v0.3.0` 压掉了 656 tokens、较 `v0.2.0` 压掉了约 32%、较 `head_1b6aaa02` 压掉了 1,753 tokens，挂载 4 个 eager 工具与 `rules/AGENTS.md` 在 Gemini 首轮仍会增加约 `2,648` input tokens。纯一次性独立工作区建议按需采用单项目安装（`node scripts/install.mjs install --project /path/to/repo`）。
